# Student Portal System

## Project Description

The Student Portal System is a simple web-based application developed using HTML and CSS. It provides students with easy access to their academic information such as personal details, enrolled courses, attendance records, and CGPA.

## Features

* Student Profile Information
* Course List Display
* Attendance Tracking
* CGPA Display
* Responsive Design
* Clean User Interface

## Technologies Used

* HTML5
* CSS3

## Project Structure

```
Student-Portal-System/
│
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any web browser.
